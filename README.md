# arg4-boletim

Edições do Boletim ARG4, publicadas em https://arg4negocios.com.br/boletim/

- `edicoes/index.json`: lista das edições (slug, data, título, resumo, arquivo), a mais recente primeiro.
- `edicoes/<slug>.md`: texto de cada edição, em Markdown.

Conteúdo informativo. Não é parecer nem recomendação para um caso específico.
